# La Cazuela de Manuela · web

Web estática (HTML + CSS + JS, sin compilar) con GSAP, ScrollTrigger, SplitText y Lenis cargados desde CDN.

- `index.html`: contenido, SEO local y datos estructurados (Restaurant + FAQ).
- `assets/css/style.css`: estilos (azulejo valenciano, pizarra, cazuela de barro).
- `assets/js/main.js`: animaciones, menú de azulejos, contador de "arroz de los viernes".

## Antes de publicar
- Pedir fotos grandes al restaurante: las de `assets/img/` son miniaturas de Google (112–224 px).
- Confirmar el horario completo (ahora solo pone "abrimos a las 7:00").
- Añadir el enlace de Instagram cuando se sepa el usuario.
- Actualizar el menú del día de la pizarra (`#menu-del-dia` en `index.html`).
- Reseñas: solo reales copiadas de Google, nunca inventadas.

## Publicar en GitHub Pages
Sube el contenido de esta carpeta a la raíz de un repositorio nuevo y activa
Settings → Pages → "Deploy from a branch" → `main` / root.
